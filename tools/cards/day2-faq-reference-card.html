Day 2 FAQ · Common Participant Questions

Quick answers to the questions that come up most. .NET AI with Claude Workshop.

Q1"My Pro subscription works for Claude Code. Why do I need an API key today?"

Your plan powers Claude.ai and Claude Code. Day 2 calls the Anthropic API directly, and the API always uses a Console key. Max and Team plans include a monthly API credit you link to a Console organization; on Pro the API is pay-as-you-go.

2"Which NuGet package is the official one?"

Anthropic (v13.x). Community options exist (Anthropic.SDK, Claudia). Old tryAGI.Anthropic v3.x is a different lineage: migrate / upgrade.

3"Why register AnthropicClient as a Singleton?"

It holds an HttpClient internally; Scoped / Transient leads to socket exhaustion, the same reason you use IHttpClientFactory.

4"Do I need an OpenAI key for the RAG section?"

No. Use the free / local path (Ollama + nomic-embed-text) behind the same EmbeddingService interface; set the Qdrant vector size to the model's dimensions (768).

5"How is the C# MCP server different from yesterday's GitHub MCP server?"

Yesterday you used a server as a host; today you build one with the C# SDK (v2.x). Same architecture (host / client / server; tools / resources / prompts), exposed over Streamable HTTP, stateless by default, so any host, including Claude Code, can call it.

6"How do I keep API costs under control?"

Prompt caching (95% off cached input on Opus/Sonnet 5.5), batch processing, Sonnet 5.5 for mechanical / CI work, and per-request + per-user token budgets. See the Models & Cost Reference.

7"How do I actually enforce our AI governance rules?"

Deterministic controls, not prompts: PreToolUse hooks, permissions, and managed settings (org-wide, non-overridable). Ties back to Day 1, Section 2.
